# MeowLauncherCli

純命令列的 Minecraft 啟動器。Busbox 風格，無互動介面。

## 快速開始

```
meowlaunchcli            # 顯示幫助
meowlaunchcli version    # 顯示版本
```

## 可用指令

| 指令 | 說明 |
|------|------|
| `help` | 顯示此幫助列表 |
| `version` | 顯示 MeowLauncherCli 版本 |
| `account local add <使用者>` | 新增本機離線帳號 |
| `account local del <使用者>` | 移除本機離線帳號 |

另見：
- [帳號管理](account.md)
- [遊戲版本切換](game.md)

其他指令（install、remove、update、search、game、mod、world、
resource、config）尚在開發中。
