# MeowLauncherCli

[日本語](README-ja_JP.md) [English](README.md) [繁體中文](README-zh_TW.md)

> 中国式な親が通報のしようがない Minecraft ランチャー——ターミナルで動くその姿は、「何でも子どもを害するもの」だと思い込む彼らの目には、真面目な開発作業にしか映らない。

## 概要

MeowLauncherCli は **Pure CLI な Minecraft ランチャー**です。Minecraft プレイヤーに必要なほぼすべて——バージョン、Mod、スキン、ワールドなど——を、GUI を一切持たない単一のスクリプト可能なコマンドラインアプリに集約することを目指しています。

ウィンドウもアイコンもトレイ常駐もありません。あるのはターミナルだけ。画面を覗き込まれても、真面目に開発作業をしているようにしか見えません。

## 機能

- **バージョン管理** — Minecraft のリリース版とスナップショット版をインストールして切り替え。
- **Mod 管理** — コマンドラインから Mod をインストール、有効化、無効化。
- **リソースパック / シェーダー** — テクスチャパック、リソースパック、シェーダーパックを管理。
- **スキン管理** — GUI を一切開かずにスキンを変更。
- **ワールド / セーブデータ管理** — ワールドの一覧表示、バックアップ、復元。
- **アカウント** — オフラインアカウントに対応。Microsoft アカウントでのログインは対応予定。
- **起動設定** — `config.json` で JVM 引数、ゲームディレクトリ、メモリ上限を設定。
- **サーバーブックマーク** — サーバーアドレスを保存し、素早く参加。
- **ローカライズ** — 英語・繁体字中国語・日本語に対応。`lang/*.json` で管理。
- **スクリプト可能** — すべての操作がサブコマンドとして公開され、シェルスクリプトや自動化と組み合わせやすい。

## アーキテクチャ

```
cmd/main/main.c           エントリポイント。app_run() を呼ぶだけ
internal/app/             アプリケーションのライフサイクル：初期化、イベントループ、クリーンアップ
internal/                 内部モジュール。外部には公開しない
lang/                     UI 文字列：en.json, zh-TW.json, ja-JP.json
scripts/                  ビルド / テストスクリプト
tests/                    テストスイート
```

MeowLauncherCli は **C11** で書かれ、**musl libc** をターゲットとすることで、小さく静的リンクされた単一バイナリを目指します。モジュールは `internal/` 配下に分離され、内部関数は原則 `static` とし、外部ライブラリに頼らず C 標準ライブラリを優先します。

## ビルド

```sh
./scripts/build.sh
```

C11 対応コンパイラが必要です。ターゲット環境に合わせて musl ツールチェーン（`musl-gcc` など）を推奨します。ビルドスクリプトは開発初期のため、整備を進めているところです。

## 設定

`config.json.example` を `config.json` にコピーし、必要に応じて編集してください。ユーザー向けの文字列はすべて `lang/` に外部化されており、表示言語はロケール設定に追従します。

## 現況

開発初期段階です。モジュール境界と骨組みは整い、機能はモジュール単位で順次実装されていきます。
